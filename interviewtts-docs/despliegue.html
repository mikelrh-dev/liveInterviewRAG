Despliegue en Produccion

Restricciones reales: Oracle Free Tier ARM64, 4 cores, 24GB RAM, $0/mes. Sin GPU, toda inferencia CPU-bound.

La Restriccion: $0/Mes

Uno de los objetivos del proyecto era demostrar que se puede construir un sistema de IA funcional sin gastar dinero en infraestructura. Esto es relevante para estudiantes sin presupuesto para GPUs, prototipos donde el costo no debe superar el MVP, y aprendizaje: cuando no puedes escalar con dinero, aprendes a escalar con ingenieria.

ARM64 vs x86

ARM64 es una arquitectura RISC con mejor eficiencia energetica. Para inferencia CPU, ARM64 ofrece buen balance precio/rendimiento. CTranslate2 y PyTorch tienen soporte nativo.

Sin GPU: CPU-Bound

Sin GPU, toda la inferencia es CPU-bound. Esto impacta directamente: Whisper STT toma ~1.5-2.5s por turno (vs ~200-500ms en GPU), embeddings ~50ms por chunk (vs ~5ms en GPU), y Pocket TTS funciona bien en CPU.

El bottleneck principal es Whisper. Con 4 cores ARM64, procesamos ~1.5s de audio por segundo real. No es tiempo real, pero es suficiente para una conversacion con pausas naturales.

Nginx + Systemd

El stack de despliegue es deliberadamente simple:

# /etc/nginx/sites-available/interviewtts server { listen 443 ssl; server_name interviewtts.example.com; location / { proxy_pass http://127.0.0.1:8000; proxy_buffering off; # Critical para SSE proxy_cache off; } }

Lo critico: proxy_buffering off. Sin esto, Nginx buffera las respuestas y el streaming SSE se rompe.

# /etc/systemd/system/interviewtts.service [Service] ExecStart=/usr/bin/python3 main.py WorkingDirectory=/opt/interviewtts Restart=always RestartSec=5
